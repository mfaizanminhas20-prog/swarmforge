# SWARMFORGE

**A Dynamic Multi-Agent Task Allocation, Scheduling and Failure-Recovery System**

SWARMFORGE is a domain-agnostic mission orchestrator. Give it any goal (build a REST API, plan a wedding) and it:
1. Breaks the mission into smaller tasks
2. Builds a dependency graph (DAG)
3. Assigns each task to the best-suited AI agent
4. Runs tasks in parallel
5. Re-plans live when failures occur
